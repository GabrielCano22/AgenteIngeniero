# Documentación y entregables

Basada en las prácticas útiles de Document Generator y en la revisión de la skill PDF de Codex. No presupongas que las herramientas o contratos internos de Codex existen en OpenCode.

1. Define audiencia, objetivo, formato, plantilla, idioma, criterios y fuentes. Diferencia información facilitada, supuestos y referencias verificadas; no inventes fuentes, resultados o citas.
2. Preserva el archivo original y elige formato editable adecuado. Comprueba herramientas y bibliotecas disponibles antes de prometer una salida. Respeta las preferencias de ubicación del usuario.
3. Emplea estilos coherentes, jerarquía de títulos, tablas legibles, imágenes con texto alternativo cuando sea posible y numeración adecuada. Para hojas de cálculo revisa tipos, fórmulas, unidades y resultados; no calcules manualmente como si un motor hubiera recalculado el archivo.
4. Reabre y verifica el archivo generado. Para PDF, extrae texto y, si hay renderizador, inspecciona imágenes de páginas; para DOCX, PPTX y XLSX valida estructura y render cuando haya herramientas. Si no puedes comprobar algo, indícalo.
5. En formularios PDF distingue valores AcroForm de apariencias de widgets; no aplanes formularios ni alteres documentos firmados sin autorización explícita.
